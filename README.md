# Uma Visual Sorting

用赛马娘 Q 版角色演示排序算法的可视化网页。角色大小对应数值，比较时显示关系提示，交换时跳跃换位；柱状图、算法代码高亮和步骤说明同步更新。

**[在线体验 → https://sort.0xcjy.top](https://sort.0xcjy.top/)**

当前网页使用 **TypeScript + Three.js + Vite**，直接在浏览器中渲染角色，不依赖 Unity WebGL 构建、IL2CPP 或 Unity WASM 运行时。

## 功能

- 五种排序算法：快速排序、插入排序、冒泡排序、选择排序、猴子排序。
- 播放 / 暂停、单步、回退、进度拖动、重置和随机打乱。
- 角色数量可调：**2–12**；播放速度可调：**0.25×–3×**。
- 两套角色模型与骨骼动画，包含待机、跳跃交换和完成后的舞蹈庆祝。
- 角色表情、头顶数值、枢轴标识、比较提示及脚底阴影。
- 头发、耳朵、尾巴的次级运动，可通过物理开关关闭。
- 总音量、角色语音、排序音效、背景音乐分别调节，支持静音。
- 响应式布局、舞台边界裁剪和全屏按钮。

## 本地运行

### 环境要求

- Node.js **20.19+（20.x）或 22.12+**，建议使用受支持的 LTS 版本。
- npm。
- 支持 WebGL 的现代浏览器；声音使用 Web Audio API，全屏功能受浏览器支持和权限限制。

### 安装与启动

```bash
git clone https://github.com/0xcjy/UmaVisualSorting.git
cd UmaVisualSorting
npm ci
npm run dev
```

打开终端输出的本地地址，默认是 `http://127.0.0.1:5173/`；端口被占用时 Vite 会选择其他端口。

仓库根目录就是网页项目，无需再进入 `web/`，也无需安装 Unity 或重新提取角色资源。运行所需的模型、纹理、音频和字体已放在 `public/`。

不要直接双击 `index.html`：应用需要通过 HTTP 服务加载模块和资源。

## 操作说明

| 操作 | 效果 |
| --- | --- |
| 算法下拉框 | 切换排序算法，并从当前初始数组重新开始 |
| 播放 / 暂停 | 自动推进步骤，或暂停当前播放 |
| 单步 | 前进一个步骤；交换步骤会播放换位动画 |
| 上一步 | 回到前一个步骤 |
| 进度条 | 跳转到指定步骤并暂停播放 |
| 重置 | 恢复参考数组并回到起点 |
| 打乱 | 随机打乱数组并回到起点 |
| 数量 / 速度 | 调整参与排序的元素数量及播放速度 |
| 物理开关 | 开启或关闭头发、耳朵、尾巴的次级运动 |
| 声音设置 | 调整各音频通道音量或静音 |
| 全屏 | 请求进入 / 退出浏览器全屏 |

键盘快捷键：**空格**播放 / 暂停，**←**上一步，**→**单步。焦点在输入框、下拉框、按钮等控件中时，不接管这些快捷键。

浏览器通常不允许页面自动播放声音。首次点击播放、单步或操作声音设置后，应用才会解锁音频并加载声音资源。

### 猴子排序说明

猴子排序发现逆序后会随机洗牌，再重新检查是否有序，**不保证在固定时间内完成**。元素越多，等待时间可能越长，建议从少量元素开始体验。

它的步骤按需生成，不预先计算完整轨迹；进度条只能访问已经生成的步骤，步骤总数后的 `+` 表示仍可能继续增长。其他四种算法会预先生成完整轨迹。

## 构建与预览

```bash
npm run build
npm run preview
```

构建命令依次执行 TypeScript 类型检查、Vite 生产打包和文本资源 gzip 预压缩。产物位于 `dist/`，其中 `.gz` 文件供支持静态 gzip 的服务器使用。

`npm run preview` 用于本地检查生产构建，访问终端输出的地址；它不是生产服务器。`node_modules/` 和 `dist/` 均不纳入 Git。

## 部署

这是静态网页，无需应用后端。将 **`dist/` 中的全部内容**部署到静态服务器即可。

当前资源路径使用 `/models/`、`/audio/`、`/fonts/` 等根路径，因此应部署在域名根目录。若要部署到子路径，需要同时调整资源请求路径和 Vite 的 base 配置；仅修改页面地址并不足够。

[deploy/nginx.conf](deploy/nginx.conf) 提供当前站点的 nginx 配置参考，包含 HTTPS 跳转、静态 gzip 和缓存策略。用于其他服务器时，需修改：

- 域名和跳转地址。
- 静态文件根目录、ACME 验证目录及日志路径。
- TLS 证书、私钥和相关配置文件的路径。

使用 `gzip_static on` 需要 nginx 支持相应模块；不支持时可移除此配置并正常提供未压缩文件。证书路径只是配置引用，仓库不包含证书或私钥。

## 项目结构

```text
.
├── src/
│   ├── algorithms.ts        # 算法元数据与排序事件生成
│   ├── playback.ts          # 播放状态、步骤历史及跳转控制
│   ├── stage.ts             # Three.js 舞台、模型、动作和坐标投影
│   ├── secondary-motion.ts  # 角色次级运动
│   ├── ui.ts                # 控件、柱状图、代码高亮和舞台覆盖层
│   ├── audio.ts             # Web Audio 音频加载与播放控制
│   ├── contracts.ts         # 共享数据类型
│   ├── main.ts              # 应用入口与帧循环
│   └── style.css            # 页面样式与响应式布局
├── public/
│   ├── models/              # 角色骨骼、网格、动作数据及纹理
│   ├── audio/               # 角色语音和排序音效 / 音乐
│   └── fonts/               # 界面字体
├── scripts/compress.mjs     # 生产文本资源 gzip 预压缩
├── deploy/nginx.conf        # nginx 配置参考
├── index.html
└── package.json
```

排序算法生成事件，播放控制器决定当前步骤和动画进度；Three.js 舞台、HTML 界面和音频根据同一播放状态更新。页面显示的 Python 风格代码用于讲解，实际排序逻辑由 TypeScript 实现。
